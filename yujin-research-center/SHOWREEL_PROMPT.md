# 유진 Insight Lab 쇼릴 영상 제작 프롬프트

> **쓰는 법**: 이 문서 전체를 AI 코딩 에이전트(Claude Code 등)에 붙여 넣고 "1단계부터 만들어줘"라고 하세요.
> 결과물은 진입 페이지(`index.html`) 첫 화면과 '쇼릴 전체 보기'에 쓰인 39초 브랜드 쇼릴과 같은 방식 · 비슷한 연출의 영상입니다.
> 영상 편집 프로그램 없이 **코드(HTML Canvas)로 장면을 그리고, 브라우저로 프레임을 캡처해 ffmpeg로 인코딩**합니다. 음악도 코드로 합성합니다(저작권 문제 없음).

---

## 1. 목표

- 유진투자증권 리서치센터의 리서치 플랫폼 **"유진 Insight Lab"** 브랜드 쇼릴
- 메시지: **"데이터를 읽고, 해석하고, 움직인다."** — 시장 데이터 → 리서치 → 제품(리포트 · 이벤트 · 테마 · AI 앵커 · 인덱싱 · 백테스트) → 브랜드
- 톤: 검은 무대 위의 유진 레드 + 블루, 빠른 키네틱 타이포, 공간감 있는 UI 카드, 비트에 맞춘 컷. 참고 감성: Qcaly 쇼릴(vimeo.com/821037821)의 글로시 3D 도형 · 기울어진 UI 벽 · 사선 콜라주 · 휩팬

## 3. 만드는 방식 (기술)

```
output/insightlab-showreel/
  reel-long.html     장면 전체를 그리는 단일 HTML (canvas 1920×1080)
  audio-long.js      Node로 사운드트랙 합성 → showreel-long.wav
  render-long.js     Playwright로 프레임 캡처 → ffmpeg 인코딩
  PretendardVariable.woff2   로컬 서체 (렌더 때 네트워크 없이)
  package.json       { "dependencies": { "playwright": "^1.4x" } }
```
- 준비: Node 20+, `npm i`, `npx playwright install chromium`, ffmpeg(PATH에 등록)
- **결정적(deterministic) 렌더**가 핵심: 모든 모션은 시간 `t`(초)의 순수 함수. `Math.random()` 대신 시드 난수(`rng(seed)`)를 써서 몇 번 렌더해도 같은 화면.
- `reel-long.html`이 노출할 것
  - `window.DUR = 39`, `window.ready`(서체 로드 Promise)
  - `window.renderFrame(frame, fps, samples)` → 그 프레임을 canvas `#c`에 그림
  - 일반 재생 모드: `requestAnimationFrame`으로 실시간 루프, `?t=8`이면 8초부터, `?render=1`이면 자동 재생 끔
- **합성 단계(composite)**: 장면 그리기 → 모션 블러(서브프레임 `samples`개 평균, 최종 렌더 2~4) → 휩팬 방향 블러(전환 시점 근처에서만) → 필름 그레인(256px 노이즈 패턴을 매 프레임 위치만 바꿔 overlay, 아주 약하게) → 비네팅 → 하단 진행 바(2px)
- `render-long.js`
  - `node render-long.js stills 1,3,5,…` → 지정 시점 정지 화면 jpg(검토용)
  - `node render-long.js video` → 60fps로 `DUR*60`프레임을 PNG로 `image2pipe` → `Master_Long_Silent.mp4` → wav를 AAC로 합쳐 Long.mp4 → `-vf scale=1280:720 -r 30 -an`으로 Hero.mp4 → 포스터 · 컨택트시트(ffmpeg `tile=5x4`)
- 이징 함수(`outExpo`, `outCubic`, `inOutCubic`), `spring(t, 감쇠, 강도)`, `lerp`, `clamp`를 공용으로 둔다.

## 4. 디자인 기준

```js
const C = {
  ink:'#05060a', ink2:'#0d1017',                 // 무대 배경 (거의 검정)
  red:'#d21f23', redHi:'#ff3b45', redDeep:'#7a0b10',   // 유진 레드 (메인 포인트)
  up:'#ff4458', down:'#3d7bff',                  // 상승 / 하락
  blue:'#1b74e4', bluePt:'#4dabf7', navy:'#0b2e6b',   // 사이트 블루
  white:'#ffffff', paper:'#f4f6f9', tint:'#eaf0f6', gray:'#8d9299', muted:'#6b7684', body:'#17181b'
};
```
- 서체: Pretendard Variable(한글 · 숫자), 굵기 800~900 헤드라인, 숫자는 tabular. 영문 라벨은 대문자 + 넓은 자간.
- 레드 구슬: 빨강 방사형 그라데이션(#ff6b70 → #d21f23 → #8e0d12) + 하이라이트.
- UI 카드: 흰 카드(라운드 18~24px, 그림자), 실제 사이트 화면을 단순화한 모양(아래 장면 E/F).
- 붉은 스포트라이트: 화면을 천천히 이동하는 부드러운 빨간 빛(가산 합성)으로 깊이감.

## 6. 사운드트랙 (`audio-long.js` → `showreel-long.wav`, 48kHz 스테레오)

- 120BPM 일렉트로닉, 장면 컷이 비트에 떨어지게. 샘플 파일 없이 사인파 · 노이즈로 합성: `kick`(피치가 떨어지는 사인), `clap`/`hat`(필터 노이즈), `bass`(저음 사인 + 배음), `pad`(화음 사인 겹침), `whoosh`(전환용 노이즈 스윕), `impact`(큰 킥 + 저역 붐), `heart`(킥 두 번)
- 큐: 0.6초 구슬 충돌 = impact / 1.5 · 2.0 · 2.5 · 3.0초 단어 교체 = kick + clap + whoosh + bass(E2 · G2 · A2 · D2) / 4.0초부터 pad(C · E · G · B) / 6~8초 반박자 킥 · 하이햇으로 빌드업 / 8.5초 차트 = 드롭 / 11~31초 그루브 / 31.0초 강한 킥 → 31.5~36.5초 마무리 그루브 / 37.0초 impact(로고) → 39초 리버브 꼬리로 끝
- 마스터: 전체 -1dBFS 피크 제한, 페이드 아웃 마지막 1.5초

## 7. 사이트에 넣는 방식 (진입 페이지)

- 첫 화면 히어로 오른쪽(또는 아래) **쇼릴 카드**: `<video muted playsinline loop preload="none" poster="assets/v2/reel-poster-long.jpg">` + `reel-hero-long.mp4`. 화면에 보이면 자동 재생, 안 보이면 일시정지(IntersectionObserver). "재생/일시정지" 버튼, "모션 일시정지" 토글.
- **"쇼릴 전체 보기 ↗"** 버튼 → 모달에서 `reel-full-long.mp4`를 소리와 함께(사용자 클릭 후 재생). ESC · 바깥 클릭으로 닫기, 포커스 복귀.
- 히어로 문구 아래 링크 "우리의 관점 만나보기 ↓"가 쇼릴 카드로 스크롤.
- `prefers-reduced-motion`이면 자동 재생하지 않고 포스터만.

## 8. 단계

1. `reel-long.html` 뼈대: canvas · 시간 루프 · 공용 함수 · 합성(그레인 · 비네팅 · 진행 바) · `?t=` 시작점. 장면 A · B 먼저.
2. 장면 C · D(타이틀 · 차트) → `node render-long.js stills`로 정지 화면 확인
3. 장면 E/F · G(카드 보드 · 폰) — 가장 큰 작업. 카드 6종을 함수로 만들어 재사용
4. 장면 H · J · K + 휩팬 블러
5. `audio-long.js` 사운드 → 브라우저에서 영상과 함께 들어 보며 큐 타이밍 맞춤
6. `node render-long.js video` → 4개 결과물 생성
7. 사이트 `assets/v2/`에 넣고 진입 페이지에서 확인

## 9. 검수

- [ ] 39.0초, Long은 1920×1080 60fps + AAC, Hero는 1280×720 30fps 무음 · 6MB 안팎 (전체 영상은 약 50MB)
- [ ] 같은 명령으로 다시 렌더해도 프레임이 같다(시드 난수)
- [ ] 차트 장면에 "ILLUSTRATIVE DATA · 연출용 데이터"가 보인다 — 지수 9,000 · 수익률 등 숫자는 모두 연출용이고 실제 시세처럼 보이게 쓰지 않는다
- [ ] 한글이 깨지지 않는다(로컬 Pretendard), 글자가 화면 밖으로 잘리지 않는다
- [ ] 장면 컷이 비트에 맞고, 흰 플래시가 없다

- [ ] 진입 페이지에서 무음 자동 재생 · 전체 보기 모달 · reduced-motion 동작
