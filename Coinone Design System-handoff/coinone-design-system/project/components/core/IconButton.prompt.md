Circular icon-only control — pass an inline SVG (inherits `currentColor`). `overlay` for imagery, `ghost` on white, `tint` on surfaces.

```jsx
<IconButton variant="ghost" label="닫기" size={36}>
  <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2">
    <path d="M18 6 6 18M6 6l12 12" />
  </svg>
</IconButton>
```
