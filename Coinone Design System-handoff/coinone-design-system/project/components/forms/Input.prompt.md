Labeled text field. Focus ring is the accent outline blue; `error` turns the border + helper red.

```jsx
<Input label="이메일" placeholder="you@coinone.co.kr" helper="가입에 사용할 이메일을 입력하세요" />
<Input label="수량" suffix="BTC" defaultValue="0.0214" />
<Input label="비밀번호" type="password" error="비밀번호가 일치하지 않습니다" />
```
